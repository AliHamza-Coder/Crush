# Plan: Professional One-Click Installation

## Goal
Users can install CRUSH with a single command or double-click. No manual extraction, no PATH configuration.

## Approach: NSIS Installer + .deb + macOS

### 1. Windows NSIS Installer
**What it does:**
- Double-click `crush-setup.exe` → wizard appears
- Select install directory (default: `C:\Program Files\CRUSH`)
- Auto-adds to system PATH
- Creates Start Menu shortcut
- Registers in "Add or Remove Programs"
- Uninstaller included

**Files to create:**
- `installer/windows/crush.nsi` — NSIS script

**CI changes (release.yml):**
- Install NSIS on Windows runner
- Run `makensis installer/windows/crush.nsi`
- Upload `crush-setup.exe` as release artifact

### 2. Linux .deb Package
**What it exists:** Already working in release.yml
**Keep as-is:** `crush_{version}_amd64.deb`

### 3. macOS Build
**CI changes (release.yml):**
- Add `build-macos` job (runs-on: macos-latest)
- Build for both x86_64 and aarch64 (Apple Silicon)
- Package as `crush-{version}-macos-x64.tar.gz` and `crush-{version}-macos-arm64.tar.gz`
- Upload as release artifacts

### 4. Install Scripts Update
**Windows (`install.ps1`):**
- Downloads `crush-setup.exe` from GitHub Releases
- Runs it silently: `crush-setup.exe /S`
- Done — no git clone, no cargo build

**Linux (`install.sh`):**
- Detects architecture
- Downloads `.deb` package
- Runs `sudo dpkg -i crush.deb`
- Done — no git clone, no cargo build

**macOS (`install.sh`):**
- Detects architecture (x86_64 or arm64)
- Downloads `.tar.gz`
- Extracts to `/usr/local/bin/`
- Done

### 5. README Update
One-line install commands:
```
Windows: irm https://raw.githubusercontent.com/.../install.ps1 | iex
Linux: curl -fsSL https://raw.githubusercontent.com/.../install.sh | bash
macOS: curl -fsSL https://raw.githubusercontent.com/.../install.sh | bash
```
